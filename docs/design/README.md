# Design StoryPocket — direzione visiva

Il nome **StoryPocket** è stato confermato. Durante la progettazione sono stati
confrontati diversi mockup: inizialmente viola, poi più vicini ai gradienti
fotografici e infine più puliti e professionali.

## Scelta finale attuale
- Colori principali: **viola / fucsia / arancione**, con sfumature vive.
- Aree contenuto: fondo chiaro, card bianche, testo nero/viola scuro.
- Interfaccia mobile: pulsanti grandi, spaziature ampie, stato del salvataggio leggibile.
- Icona: download o media dentro una tasca stilizzata; evitare di copiare
  il marchio Instagram.
- Mantenere il flusso in primo piano: **Condividi → riconosci contenuto → salva**.
- Preservare l'usabilità in verticale e orizzontale.
- Non mostrare download riusciti o anteprime non realmente disponibili.

I concept illustrativi creati nella conversazione rimangono materiale di
riferimento della progettazione; non sono screenshot delle funzioni reali e
non sono necessari per compilare l'app Android.

## Migliorie previste
- UI Material con stato di analisi, download in corso, completato/errore.
- Anteprima media quando affidabile; non confondere cover con file video.
- Raccolta file salvati, filtri foto/video e un tema scuro opzionale.
- Palette accessibile: contrasto sufficiente e animazioni non invasive.
